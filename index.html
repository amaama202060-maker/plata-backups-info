PLATA Backups

PLATA Backups is a private backup utility intended for use by the operator of the PLATA web platform. It helps the operator transfer and retain encrypted server backup archives in a Google Drive account they control.

Purpose and Google Drive access

The utility uses an authorized Google Drive connection to create and maintain backup files. Access is requested only by the account owner or authorized administrator. The intended permission is limited to files created or used by this integration.

Backup files are intended to be encrypted before transfer to Google Drive. No server backups, OAuth credentials, user records or bank data are hosted in this public information repository.

Not a customer-facing service

This page describes a private system-administration integration only. It is not a banking login, payment service or an application for public account registration.
